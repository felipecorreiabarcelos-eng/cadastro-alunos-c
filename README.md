# cadastro-alunos-c
Sistema de cadastro de alunos desenvolvido em linguagem C, utilizando structs e vetores. Permite cadastrar, listar, buscar, editar e remover alunos (nome, idade, matrícula, curso, CPF, telefone e email) através de um menu interativo no terminal. Projeto acadêmico feito para praticar structs e manipulação de dados em C.
